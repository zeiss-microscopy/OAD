    extract_czexp_plan#

    zen_api_utils.extract_czexp_plan #

    Extract a provisional CZI/CZMBI acquisition plan from a ZEN Experiment XML file.

    Disclaimer: This script is intended for experimental use and may not cover all edge cases of ZEN Experiment XML files.

    Run from the repository root:

    python experimental\extract_czexp_plan.py experimental\ZEN_API_Test_CD7_split.czexp

    Write a reduced JSON plan and a CZMBI file in one call:

    python experimental\extract_czexp_plan.py `
    experimental\ZEN_API_Test_CD7_split.czexp `
    --reduced `
    --output experimental\plan.json `
    --czmbi-output experimental\hcs.czmbi

    The JSON plan is always written first. When --czmbi-output is present, the script reloads that JSON and projects its first acquisition block to CZMBI 1.0. CZMBI generation requires split-scene acquisition with one planned CZI per scene. When ZEN does not expose exact output names, the generated CZMBI uses deterministic suggested_filename values that must be validated against actual ZEN output.

    Index convention (plan schema 0.2 and typed positions): all block, scene, well-row, well-column, well and field indices are zero-based. Block indices refer to the original XML order, including skipped inactive blocks. Well indices follow first appearance within each block; field indices restart per well, with unassigned fields forming a separate group per block. Counts are not indices. Well labels remain unchanged (B3 maps to row 1, column 2). XML and CZMBI one-based coordinates are converted at their input/output boundaries. Stage coordinates and full rectangular region dimensions are in micrometers.

    CarrierGeometry dataclass #

    CarrierGeometry(rows: int, columns: int, center_x_um: float, center_y_um: float, pitch_x_um: float, pitch_y_um: float, well_width_um: float, well_height_um: float)

    An unrotated rectangular well grid in absolute stage micrometers.

    Only centered regular grids with unswitched, noninverted axes and a zero TopLeft reference are supported. Width/height must be smaller than pitch: touching/overlapping wells are rejected to avoid ambiguous edge assignment. All physical wells are considered, regardless of selected well containers.

    Coordinates must share the experiment's stage origin, calibration and plate placement. This model cannot verify that condition or correct stage drift. It classifies points, not whole images or tile footprints; Z is irrelevant.

    locate #

    locate(x_um: float, y_um: float) -> WellAssignment | None

    Return the containing well, or None for gaps/outside the plate.

    Rectangle edges are included, without an added tolerance or snapping. Non-finite input raises ValueError rather than appearing unassigned.

    assign_positions #

    assign_positions(xy_um: Sequence[tuple[float, float]]) -> list[WellAssignment | None]

    Return one assignment per input XY pair, preserving order and duplicates.

    None means a valid point lies outside every configured well rectangle, not that the template is unsupported. Unsupported geometry fails when loaded; invalid coordinates raise rather than produce a partial result.
