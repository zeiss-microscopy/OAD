    Changelog#

    All notable changes to the ZEN API project will be documented in this file.

    The format is based on Keep a Changelog. Package versions follow the format YYYY.MM.PATCH.

    [Unreleased]#

    Added#

    • Maintained zen_api_utils package for reusable acquisition, hardware, streaming, and OME-Zarr utilities
    • MkDocs API reference documentation generated from the Python package using mkdocstrings (Material theme)
    • New generate_mkdocs_pages.py script to auto-generate API reference pages from the zen_api module tree
    • New $BUILD_MKDOCS option in create_python_packages.ps1
    • GitHub Actions workflow for building package artifacts and deploying versioned MkDocs documentation to GitHub Pages
    • Versioned documentation support via mike

    Changed#

    • Both zen_api and zen_api_utils now declare Python 3.12-3.15 only (>=3.12,<3.16); Python 3.10 and 3.11 support is dropped.
    • Package and documentation publication is gated on compatibility tests for Python 3.12, 3.13, 3.14, and 3.15.
    • Moved reusable streaming and OME-Zarr functionality into zen_api_utils, including the zenapi-stream2omezarr command
    • Replaced WeasyPrint with Playwright (Chromium) for HTML-to-PDF conversion — no native GTK/Pango libraries required
    • generate_python_wrappers.py can now resolve protoc from PATH when no explicit install path is provided
    • Local PowerShell packaging uses the zenapi conda environment by default

    Fixed#

    • Streaming example now selects the working PySide6 backend before importing pyqtgraph and qasync
    • generate_python_wrappers.py and build_wheel_package.py now propagate exit codes via sys.exit() so failures are correctly detected by the build script
    • Added $LASTEXITCODE checks after git checkout and git pull in create_python_packages.ps1 to fail fast on git errors
    • Quoted --label, --proto-root, and --output-dir arguments in docbuilder invocation to handle paths/labels with spaces
    • Fixed typo in $ZEN_API_DOCS_LABEL separator (Version:- → Version:)

    [2026.05.1] - 2026-05-01#

    Added in 2026.05.1#

    • Proto definitions for ZEN Release 3.14 (Spring 2026)
    • PDF conversion support via WeasyPrint in clean_html_badges.py
    • Automatic fontconfig setup for WeasyPrint on Windows
    • --delete_cleaned_html flag to remove temporary cleaned HTML files after processing
    • HTML-to-Markdown conversion with GitHub-flavored Markdown support
    • Copyright header injection into generated Python files (build_wheel_package.py)
    • Invoke-CondaPython helper to avoid conda run file-locking issues on Windows
    • Comprehensive build instructions in Instructions.md

    [2025.10.1] - 2025-10-01#

    Added in 2025.10.1#

    • Initial public release of ZEN API proto definitions (ZEN Release 3.13, Autumn 2025)
    • Python wrapper generation from .proto files using betterproto
    • Wheel package build pipeline (create_python_packages.ps1)
    • HTML documentation generation via zenapi-docbuilder
    • HTML badge cleaning script (clean_html_badges.py)
    • Azure DevOps CI/CD compatible logging
