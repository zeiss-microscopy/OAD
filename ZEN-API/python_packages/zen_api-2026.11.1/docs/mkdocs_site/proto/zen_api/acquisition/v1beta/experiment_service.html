    Service ExperimentService#

    The IExperimentService interface.

    Clone#

    Clones an already loaded experiment. Useful when one wants to clone an experiment before modifying it in order to preserve the original experiment. This method returns the info needed to reference the cloned experiment.

    rpc Clone (zen_api.acquisition.v1beta.ExperimentServiceCloneRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceCloneResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceCloneRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceCloneResponse

    Delete#

    Deletes an experiment file from the predefined location on disk. It does not delete the corresponding loaded experiment instance.

    rpc Delete (zen_api.acquisition.v1beta.ExperimentServiceDeleteRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceDeleteResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceDeleteRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceDeleteResponse

    Export#

    Returns xml representation of an experiment.

    rpc Export (zen_api.acquisition.v1beta.ExperimentServiceExportRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceExportResponse);

    Response: zen_api.acquisition.v1beta.ExperimentServiceExportResponse

    GetStatus#

    Gets status of an experiment. The information is updated in interval (several times per seconds). As a result, some status updates could be skipped.

    rpc GetStatus (zen_api.acquisition.v1beta.ExperimentServiceGetStatusRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceGetStatusResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceGetStatusRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceGetStatusResponse

    Import#

    Imports an experiment from the provided experiment xml string. This method returns the info needed to reference the imported experiment.

    rpc Import (zen_api.acquisition.v1beta.ExperimentServiceImportRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceImportResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceImportRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceImportResponse

    Load#

    Loads an experiment from the available experiments. Consequently, the experiment is ready to be executed or modified. This method returns the info needed to reference the loaded experiment.

    rpc Load (zen_api.acquisition.v1beta.ExperimentServiceLoadRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceLoadResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceLoadRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceLoadResponse

    RegisterOnStatusChanged#

    Register on experiment status changed events. The information is updated in interval (several times per seconds). As a result, some status updates could be skipped. The notifications can be retrieved for experiments which are active at the time the method is invoked. If the method is invoked after an experiment is finished, the call will throw an exception.

    rpc RegisterOnStatusChanged (zen_api.acquisition.v1beta.ExperimentServiceRegisterOnStatusChangedRequest) returns (stream zen_api.acquisition.v1beta.ExperimentServiceRegisterOnStatusChangedResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceRegisterOnStatusChangedRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceRegisterOnStatusChangedResponse

    RunExperiment#

    Executes an experiment and waits until the experiment execution is finished. This means that the method will block until the experiment was successfully completed, it fails, or it is cancelled. If the call is interrupted (e.g., caller is not available anymore) the experiment will be stopped.

    rpc RunExperiment (zen_api.acquisition.v1beta.ExperimentServiceRunExperimentRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceRunExperimentResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceRunExperimentRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceRunExperimentResponse

    RunSnap#

    Acquires a single snap image with the activated channels in the specified experiment and waits until the process of acquiring snap is finished. This means that the method will block until the experiment was successfully completed, it fails, or it is cancelled. If the call is interrupted (e.g., caller is not available anymore) the snap will be stopped.

    rpc RunSnap (zen_api.acquisition.v1beta.ExperimentServiceRunSnapRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceRunSnapResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceRunSnapRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceRunSnapResponse

    Save#

    Saves a loaded experiment to the predefined location on disk.

    rpc Save (zen_api.acquisition.v1beta.ExperimentServiceSaveRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceSaveResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceSaveRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceSaveResponse

    StartContinuous#

    Starts the continuous with the activated channels in the specified experiment and waits for the acquisition to start. After that point continuous will run until it is explicitly stopped or it fails - even if the caller is not available anymore.

    rpc StartContinuous (zen_api.acquisition.v1beta.ExperimentServiceStartContinuousRequest) returns (google.protobuf.Empty);

    Request: zen_api.acquisition.v1beta.ExperimentServiceStartContinuousRequest

    Response: google.protobuf.Empty

    StartExperiment#

    Starts the process of executing an experiment and waits for the acquisition to start. After that point the experiment will either run to completion (successful or not) or until it is explicitly stopped - even if the caller is not available anymore.

    rpc StartExperiment (zen_api.acquisition.v1beta.ExperimentServiceStartExperimentRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceStartExperimentResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceStartExperimentRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceStartExperimentResponse

    StartLive#

    Starts live with the requested track in the specified experiment and waits for the acquisition to start. After that point live will run until it is explicitly stopped or it fails - even if the caller is not available anymore.

    rpc StartLive (zen_api.acquisition.v1beta.ExperimentServiceStartLiveRequest) returns (google.protobuf.Empty);

    Request: zen_api.acquisition.v1beta.ExperimentServiceStartLiveRequest

    Response: google.protobuf.Empty

    StartSnap#

    Starts the process of acquiring a single snap image with the activated channels in the specified experiment and waits for the acquisition to start. After that point the snap will either run to completion (successful or not) or until it is explicitly stopped - even if the caller is not available anymore.

    rpc StartSnap (zen_api.acquisition.v1beta.ExperimentServiceStartSnapRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceStartSnapResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceStartSnapRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceStartSnapResponse

    Stop#

    Stops the specified experiment or one of the active experiments if the experiment ID is not provided. This will stop any type of experiment (i.e., experiment, snap, continuous, live) if it is active and known to this service. This method returns the info needed to reference the stopped experiment.

    rpc Stop (zen_api.acquisition.v1beta.ExperimentServiceStopRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceStopResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceStopRequest

    Response: zen_api.acquisition.v1beta.ExperimentServiceStopResponse

    UpdateRunningExperiment#

    Updates the running experiment. Only accepts the originally started experiment id.

    rpc UpdateRunningExperiment (zen_api.acquisition.v1beta.ExperimentServiceUpdateRunningExperimentRequest) returns (zen_api.acquisition.v1beta.ExperimentServiceUpdateRunningExperimentResponse);

    Request: zen_api.acquisition.v1beta.ExperimentServiceUpdateRunningExperimentRequest
