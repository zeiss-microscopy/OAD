    Service LatticeLightsheetService#

    The ILatticeLightsheetService interface.

    FindCoverGlass#

    Finds the cover glass asynchronously. This is done by searching the z range and looking for a peak in the signal using a two-step coarse and a fine search.

    Refocuses the cover glass. It is mandatory to store a focus position before calling this method.

    Runs the tilt correction and sets the corrected values. At least 3 points are expected to run the correction.

    StoreFocus#

    Stores the current focus position. This position is e.g. used by RecallFocus to refocus on this position.

    rpc StoreFocus (zen_api.lm.lls.v1beta.LatticeLightsheetServiceStoreFocusRequest) returns (zen_api.lm.lls.v1beta.LatticeLightsheetServiceStoreFocusResponse);

    Request: zen_api.lm.lls.v1beta.LatticeLightsheetServiceStoreFocusRequest

    Response: zen_api.lm.lls.v1beta.LatticeLightsheetServiceStoreFocusResponse

    StoreFocusForAutoFocus#

    Stores the current focus position. This position is e.g. used by RecallFocus to refocus on this position. The focus sheet and focus waist parameters are taken from the given experiment. Additionally, stores the focus position for the autofocus configured in the experiment. Requires that a cover glass refocus is selected in the autofocus.

    rpc StoreFocusForAutoFocus (zen_api.lm.lls.v1beta.LatticeLightsheetServiceStoreFocusForAutoFocusRequest) returns (zen_api.lm.lls.v1beta.LatticeLightsheetServiceStoreFocusForAutoFocusResponse);

    Request: zen_api.lm.lls.v1beta.LatticeLightsheetServiceStoreFocusForAutoFocusRequest

    Response: zen_api.lm.lls.v1beta.LatticeLightsheetServiceStoreFocusForAutoFocusResponse
