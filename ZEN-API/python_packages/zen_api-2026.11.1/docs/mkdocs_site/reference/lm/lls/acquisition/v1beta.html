    ChannelServiceSyncedAllTracks #

    Bases: Enum

    Specifies the synchronization mode for tracks in multi-track acquisition scenarios.

    Attributes:

    • UNSPECIFIED –

      Protobuf requires this default.

    • NONE –

      Tracks are not synchronized.

    • ALL_TRACKS_PER_SLICE –

      Tracks are synchronized for fast track switch with "All tracks per slice" dimension ordering.

    UNSPECIFIED class-attribute instance-attribute #

    UNSPECIFIED = 0

    Protobuf requires this default.

    NONE class-attribute instance-attribute #

    NONE = 1

    Tracks are not synchronized.

    ALL_TRACKS_PER_SLICE class-attribute instance-attribute #

    ALL_TRACKS_PER_SLICE = 2

    Tracks are synchronized for fast track switch with "All tracks per slice" dimension ordering.

    Adds one or more rectangle tile regions to the experiment, stacked in Z for spanning the requested Z depth. The volumes overlap in Z by 50 pixels. If fullZ is false (default), the volume has sparse data at the sides, reconstructed Z slices do not span the whole width. If fullZ is true, the width is extended for full Z reconstruction.
