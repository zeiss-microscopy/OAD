    streaming#

    zen_api_utils.streaming #

    Headless ZEN API pixel-streaming and OME-Zarr helpers.

    Modules:

    • acquisition –

      Streaming-facing imports for shared acquisition metadata.

    • frames –

      Decode and validate ZEN pixel-stream payloads.

    • geometry –

      Coordinate-based geometry for streamed image tiles.

    • metrics –

      Pure throughput metrics for ZEN pixel-stream measurements.

    • omezarr –
    • pipeline –

      Headless ZEN-API pixel streaming and OME-Zarr writing pipeline.

    • receiver –

      Asynchronous helpers for ZEN pixel-stream consumers.

    Classes:

    • AcquisitionChannel –

      An active acquisition channel.

    • AcquisitionDimensions –

      Acquisition axes known before pixel streaming starts.

    • ExperimentAcquisition –

      Small typed snapshot of the acquisition settings used by streaming.

    • PlacedTile –

      Tile geometry resolved against a scene mosaic canvas.

    • SceneGeometry –

      Shape and physical origin of a rasterized scene mosaic.

    • TileGeometry –

      Physical geometry for one streamed image tile.

    • IntervalResult –

      Throughput accumulated over one reporting interval.

    Functions:

    • decode_frame –

      Decode a row-major grayscale payload with a caller-supplied dtype.

    • decode_pixel_payload –

      Decode a ZEN payload using its protocol pixel type metadata.

    • runtime_grayscale_dtype –

      Return and validate the dtype reported by a streamed grayscale frame.

    • assemble_channel_scene_mosaics –

      Merge (scene, time, tile, z, image) records into an STZYX array.

    • calculate_scene_geometry –

      Calculate mosaic placement from arbitrary tile center positions.

    • calculate_interval –

      Calculate rates for an interval using monotonic nanosecond timestamps.
